# Ориентир — навигатор для старшеклассников

Справочник для учеников 10–11 классов: олимпиады с льготами, курсы при университетах, вузы с проходными баллами и
востребованные профессии. Сайт подстраивается под класс, предметы ЕГЭ и регион, которые ученик указывает при первом входе.

Стек: Next.js 16 (App Router), TypeScript, Tailwind CSS 4, shadcn/ui, Motion.

## Локальный запуск

```bash
npm install
npm run dev
```

Сайт откроется на http://localhost:3000.

## Где что лежит

| Путь | Что внутри |
| --- | --- |
| `src/data/universities.ts` | вузы: направления, предметы ЕГЭ, официальные проходные баллы с годом и источником, особенности конкурса |
| `src/data/olympiads.ts` | олимпиады: уровни профилей из перечня РСОШ, этапы, что даёт каждое место |
| `src/data/rsosh.ts` | официальный перечень олимпиад школьников (генерируется, вручную не править) |
| `src/data/courses.ts` | курсы при вузах и бесплатные федеральные программы |
| `src/data/careers.ts` | профессии будущего |
| `src/data/advice.ts` | планы на 10 и 11 класс, правила поступления |
| `src/data/quotes.ts` | цитаты философов на главной |
| `src/data/credits.ts` | авторы и лицензии фотографий (Wikimedia Commons) |
| `public/images/vuzy`, `public/images/people` | вырезанные фото (WebP с прозрачностью) |

Проходные баллы — официальные цифры приёмных комиссий (бюджет, общий конкурс) с годом и ссылкой на источник; если вуз их
не публикует, `score: null`. Обновляйте их после каждой приёмной кампании.

## Деплой на Vercel

1. На [vercel.com/new](https://vercel.com/new) войдите через GitHub и импортируйте репозиторий.
2. Настройки сборки Vercel определит сам (Next.js). Переменные окружения не обязательны: адрес сайта для `sitemap.xml`,
   `robots.txt` и Open Graph берётся из `VERCEL_PROJECT_PRODUCTION_URL`. Для своего домена задайте `SITE_URL`.
3. Нажмите **Deploy**. Каждый пуш в `main` обновляет сайт автоматически.

Из России сайты на Vercel открываются не у всех провайдеров — для основной аудитории надёжнее VPS.

## Деплой на VPS через Dokploy

1. Залейте проект в репозиторий GitHub.
2. В Dokploy: **Create Application** → источник **GitHub** → выберите репозиторий и ветку `main`.
3. **Build Type**: `Dockerfile` (файл лежит в корне репозитория).
4. **Build-time arguments**: `SITE_URL=https://ваш-домен.ru` — из этого адреса строятся `sitemap.xml`, `robots.txt`,
   канонические ссылки и Open Graph.
5. **Domains**: добавьте домен, порт контейнера — `3000`, включите HTTPS (Let's Encrypt).
6. Нажмите **Deploy**. Для автодеплоя при пуше включите Auto Deploy (webhook GitHub).

Проверка после деплоя: `https://ваш-домен.ru/sitemap.xml` и `https://ваш-домен.ru/robots.txt` должны содержать ваш домен.
